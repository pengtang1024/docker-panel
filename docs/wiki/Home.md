# dvkit Wiki

**dvkit** 是一个极简的 Docker 桌面管理工具，用 Rust + egui 写成。
单二进制、无 Electron、无运行时依赖，双击启动，开箱即用。

- 仓库地址：<https://github.com/pengtang1024/dvkit>
- 许可证：MIT

## 它能做什么

### 容器

- 查看全部 / 运行中的容器：ID、名称、镜像、状态、运行时长、端口映射
- 实时资源占用：CPU、内存（用量 + 百分比）、磁盘读写、网络 IO
- 一键启动 / 停止 / 重启 / 删除，单个或勾选批量执行
- 实时跟随日志（可暂停滚动）、CPU / 内存曲线监控
- 搜索过滤、点表头排序、自定义显示列、拖拽列宽
- Compose 项目自动识别、按项目分组折叠
- 右键菜单、双击看日志、复制容器 ID

### 镜像

- 镜像列表：名称、Tag、大小、创建时间、关联容器数，悬空镜像高亮
- 在线拉取镜像，实时显示分层下载进度
- 单个 / 批量删除，关联容器数一目了然
- 搜索、排序、自定义列与容器页一致

### 清理

勾选组合一键清理：已停止的容器、悬空镜像、未使用镜像
（等价 `docker image prune -a`），执行前二次确认，完成后汇报释放空间。

## 快速开始

1. 按 [安装与构建](Install.md) 准备好 Docker 权限并装好 dvkit；
2. 启动后默认就是容器页，所有容器操作都在一屏内完成；
3. 不熟悉交互的话，看一眼 [使用指南](Usage.md) 的速查表。

## 环境要求

- Linux / macOS / Windows（主要在 Linux 验证）
- 已安装并运行 Docker（默认 unix socket，支持 `DOCKER_HOST`）
- Rust stable（仅从源码构建时需要）
