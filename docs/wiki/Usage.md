# 使用指南

dvkit 的界面分三块：**顶部品牌头**（Tab + Docker 连接状态）、
**主表格区**（容器 / 镜像两个 Tab）、**弹窗**。
所有破坏性操作（删除、清理）都会二次确认。

## 1. 容器 Tab

### 工具条（第一行）

| 控件 | 作用 |
|------|------|
| 搜索框 | 即时过滤**名称 / 容器 ID / 镜像名 / 端口 / 状态**，不区分大小写；右侧 × 一键清空 |
| 仅正在运行 / 全部 | 切换 Docker 查询范围，切换后立即重新拉取 |
| Compose 分组 | 开启后把带 compose label 的容器按项目折叠成组 |
| 显示列 | 勾选要显示的列，至少保留一列；可「恢复默认列」 |
| 刷新列表 | 立即拉取（平时每 2 秒自动无感刷新） |
| 简易清理… | 打开清理弹窗，见[第 4 节](#4-简易清理) |

### 表格列

选择框、短 ID、名称（compose 容器带青色 `compose` 角标，悬停可见项目与
服务名）、镜像、状态、运行时长、端口、CPU、内存、磁盘（R 读 / W 写）、
网络（↓ 收 / ↑ 发）、操作。

- **排序**：点任意可排序列的表头，当前排序列高亮并显示三角箭头；
  再点一次翻转升降序，换列默认升序。状态列按运行权重排
  （运行中 → 重启中 → 已暂停 → … → 已停止）。
- **列宽**：直接拖动列之间的分隔线；窗口太窄时表格横向滚动。
- **数字列**：CPU、内存、磁盘、网络右对齐；非运行容器显示 `-`；
  CPU ≥ 80% 标红。

### 鼠标操作速查

| 操作 | 效果 |
|------|------|
| 左键点行空白处 | 勾选 / 取消勾选该行 |
| 左键双击行 | 打开实时日志窗口 |
| 右键行 | 右键菜单（见下） |
| 点行首复选框 | 勾选 / 取消勾选 |
| 点表头复选框 | 全选 / 全不选（作用于当前过滤后的可见行） |

**右键菜单**：查看日志、资源监控、启动、停止、重启、复制容器 ID、删除容器。
不适用的操作自动置灰（如运行中的容器「启动」不可点）。

**行内图标按钮**（操作列）：日志、监控、启动（绿）、停止（红）、
重启（琥珀）、删除（红），鼠标悬停有文字提示。

### 批量操作

勾选一行或多行后，工具条下方出现蓝色批量操作条：

- **批量启动 / 批量停止 / 批量重启**：直接执行；
- **批量删除…**：弹出确认窗，列出待删容器（最多显示 8 项，超出显示
  「… 等共 N 项」），确认后执行；
- **清除选择**：清空勾选。

批量只作用于「勾选集 ∩ 当前可见行」，被搜索词藏起来的行不会被误操作。
部分失败时，错误窗逐行列出失败项，成功项照常生效。

### Compose 分组

开启「Compose 分组」后：

- 普通（非 compose）容器仍以普通行排在前面；
- 每个 compose 项目显示一个青色强调条组头：`项目名 · N 个容器`；
- 点组头折叠 / 展开，折叠状态在刷新后保持；
- 组内容器名称旁的 `compose` 角标悬停可看项目名与服务名。

### 日志窗口

- 打开时先加载最后 **200 行**，随后实时跟随新日志；
- 工具条：暂停滚动 / 继续滚动、清空日志；右侧显示行数与容器短 ID；
- 最多保留 5000 行，超出自动丢弃最旧的 500 行；
- 日志流中断时显示「已结束」角标；
- 关闭窗口即中断后台日志任务，不占资源。

### 资源监控窗口

- 顶部两张指标卡：CPU 当前使用率、内存用量 / 上限 / 百分比；
- 两张折线图：CPU（上限随历史峰值自适应）、内存（固定 0–100%）；
- 每 2 秒一个采样点，保留 120 点 ≈ 4 分钟历史。

## 2. 镜像 Tab

### 工具条

- 搜索框：即时过滤**名称 / Tag / 镜像 ID**；
- 显示列、刷新、清理与容器页相同；镜像列表每 **15 秒**自动刷新
  （仅停留在该 Tab 时）。

### 拉取镜像

第二行输入框填入镜像规格，例如：

```
nginx:latest
redis:7
registry.example.com:5000/myapp:v1.2
```

**回车**或点蓝色拉取按钮开始拉取；输入框下方实时显示分层进度
（含百分比）。完成后弹出结果提示并自动刷新列表；未指定 tag 时
默认 `latest`。

### 表格与操作

- 列：选择框、名称（悬空镜像为黄色 `<none>`，悬停看完整 ID）、Tag、
  大小、创建时间（相对时间，如「3 天前」）、关联容器数、操作；
- 排序、列宽、自定义列与容器页一致；
- 操作列：删除镜像；
- 右键菜单：复制镜像 ID、删除镜像；
- 勾选多行后可批量删除，确认窗列出全部 `名称:tag`；
- 被容器引用的镜像 Docker 会拒绝删除，错误信息会直接弹出。

## 3. 顶部状态

- 左侧：dvkit 标识与「容器 / 镜像」Tab；
- 右侧状态点：
  - 🟡 黄色闪烁：正在连接 Docker（启动瞬间）；
  - 🟢 绿色：Docker 连接正常；
  - 🔴 红色：连接异常（悬停有提示）；
- 状态点只跟连接健康度绑定，不会因每次列表刷新而变色；
- 旁边的文字是最近一次操作结果 / 当前容器数量。

## 4. 简易清理

点工具条的「简易清理…」，勾选清理范围：

| 选项 | 含义 | 等价命令 |
|------|------|----------|
| 已停止的容器 | 状态为 exited / created 的容器 | `docker container prune` |
| 悬空镜像 | 无 Tag 且未被引用的镜像（默认勾选） | `docker image prune` |
| 未使用镜像 | 所有未被任何容器使用的镜像，含带 Tag 的 | `docker image prune -a` |

至少勾选一项才能点「确认执行」。完成后弹窗汇报每项删除数量与
释放的磁盘空间。**清理不可恢复**，执行前请确认范围。

## 5. 弹窗约定

| 弹窗 | 触发 | 说明 |
|------|------|------|
| 删除确认 | 单个 / 批量删除 | 红色警告条 + 批量预览清单，必须点「确认删除」 |
| 错误详情 | Docker 调用失败 | 等宽字体展示完整错误；同一个错误不会连续重复弹 |
| 执行结果 | 拉取完成、清理完成等 | 绿色提示 + 明细 |
| 清理 | 点「简易清理…」 | 见上 |
| 日志 / 监控 | 行内按钮、右键或双击 | 非模态，可拖动、可与主窗口同时操作 |
