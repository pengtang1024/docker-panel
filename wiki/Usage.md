# 使用指南

> 一句话：给已经装好 Docker Panel 的人看——每个按钮和快捷键干什么、数据从哪来、哪些操作一按就不可逆。

**前置知识**：已装好且顶栏显示已连接（见 [Installation](Installation)）｜**相关页面**：[Home](Home) · [FAQ](FAQ) · [Changelog](Changelog) · [Contributing](Contributing)

> 删除无二次确认、立即执行且不可恢复：容器删除带 `force=true`，镜像删除同样立即生效。批量删除前请确认选择范围。

## 0. 界面分区

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 连接状态 / 数据过期提示 / 搜索框 / 主题 / 设置 / 刷新 / 清理 / 更新 / 拉取 |
| 筛选栏 | 容器视图专属：状态 chips / 排序 / 多选 / 视图 tabs |
| 主列表区 | 容器 = 密集台账；镜像 / 网络 / 卷 = 表格列表 |
| 底栏 | 9 项资源概览与操作反馈 |
| 右侧抽屉 | 详情 / 日志 / 环境，点击行打开 |

## 1. 全局快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+K` 或 `/` | 聚焦搜索框（在搜索框内输入时 `/` 由输入框先消费） |
| `Ctrl+R` | 手动刷新当前视图 |
| `Ctrl+1` ~ `Ctrl+4` | 切换 容器 / 镜像 / 网络 / 卷 |
| `Esc` | 关闭抽屉 / 弹窗 / 菜单，或退出多选并归还焦点 |

快捷键由根级 FocusScope 统一处理：无焦点元素时 Slint 完全不派发按键，所以启动与弹层关闭后都会归还焦点。

## 2. 顶栏、搜索与筛选

顶栏管全局状态与全局动作；筛选栏只在容器视图出现，含状态 chips（全部 / 运行中 / 已停止）、排序按钮与多选按钮。计数口径是可见容器集合：折叠 Compose 分组后概览带与 chips 同步变小。

搜索框即时过滤，四类资源共用同一关键词：容器匹配名称 / 短 ID / 镜像 / 状态 / Compose 项目与服务 / 端口；镜像匹配名称 / 短 ID / 全部 tag；网络匹配名称 / driver / scope / 短 ID；卷匹配名称 / driver / 挂载点。

## 3. 容器台账

容器视图是一张 30px 行的虚拟化台账：顶部概览带（总数 / 运行中 / 已停止 / 需关注，宽窗还有 CPU TOP4）→ 可排序表头 → 行。表头与每行逐列同 x 同宽，窄窗自动隐去磁盘 / 端口列。

| 元素 | 行为 |
| --- | --- |
| 状态点 | 「需关注」= 死亡 / 暂停 / 重启中 / 正在移除 / 异常退出（退出码 ≠ 0），行首琥珀色标记 |
| CPU / 内存微条 | docker stats 口径：CPU = 相对单核百分比 / 100，内存 = 用量 / 上限，同列同量纲可比 |
| 磁盘列 | 显示 `disk_used`（镜像 + 可写层 + 挂载具名卷）；底栏磁盘合计按 id / 卷名去重，两者口径不同不要相加 |
| 表头排序 | 可点击名称 / CPU / 内存 / 磁盘排序，排序菜单另支持按状态；三个资源列表排序各自独立并持久化 |

### 台账内联 Compose 树

项目带 → 服务带 → 容器行（1~2 级，只有多容器服务才有服务带）。点箭头或分组名展开 / 收起；分组是分组不是筛选器，排序只决定组内顺序，组间按组名稳定排；无 Compose 归属的容器直接排在顶层。收起状态持久化，新分组默认展开。

分组带通栏，显示组内资源汇总（CPU / 内存只累加运行中成员，磁盘累加全部成员），与是否展开无关；三个按钮与容器行同构但作用于组内全部成员：主按钮启动全组 / 重启全组，日志打开分组合并日志（行首 `[容器名]` 前缀），更多含停止全部 / 重启全部 / 删除全部。

### 行内操作与批量

悬停行出现 ▶ / ⏹ 启停、⟳ 重启、📜 日志、··· 更多（日志 / 停止 / 删除）。点行本身打开详情 Tab，Shift+点击可勾选。多选模式下批量栏支持启动 / 停止 / 重启 / 删除 / 取消，Esc 退出多选。只有容器视图支持多选批量。

操作完成后列表由 Docker `/events` 事件统一刷新（400ms 合并窗口：首事件立刻刷、窗口内后续事件到期补刷一次），操作消息不再自带刷新。

## 4. 镜像 / 网络 / 卷表格

| 视图 | 列 | 交互 |
| --- | --- | --- |
| 镜像 | `repo:tag` · 大小 · 创建时间 | 点行看详情；行尾 ▶ 当前只回显提示，未接入 `docker run` |
| 网络 | 名称 · driver · 子网 | 点行看详情；无行内删除入口 |
| 卷 | 名称 · 大小 · 挂载点 | 点行看详情；大小来自 30s 低频采样，刚打开可能短暂显示占位 |

网络 / 卷是只读列表，删除未使用资源请用清理弹窗或 Docker CLI。

## 5. 右侧抽屉

容器抽屉有详情 / 日志 / 环境三个 Tab；镜像 / 网络 / 卷为单页详情。

- **详情 Tab**：inspect 五组——概览（状态 / PID / ID / 磁盘）、资源（CPU% / 内存 / 重启策略与次数）、时间、网络、配置；每行可复制。
- **日志 Tab**：首次打开加载最后 200 行并实时跟随，区分 StdOut / StdErr；窗口最多保留 2000 行（超出分块裁剪保留 1000）；可暂停跟随 / 复制 / 清空。断流重连带时间戳游标（仅 `json-file` 驱动）补回窗口内的行，单次回放上限 2000 行；提示分「重连中 / 已恢复 / 已停止 / 洪峰抽样」四态。容器停止后不自动重连，需重新切到日志 Tab。
- **环境 Tab**：环境变量 / 端口映射 / 接入网络 / 挂载点。

分组合并日志为每个运行中成员建一条流，行首带来源前缀，一条流结束不代表整组结束。

## 6. 弹窗与设置

- **拉取镜像**：输入镜像规格（不写 tag 默认 `latest`），弹窗显示分层进度；完成后关弹窗，列表由事件刷新。
- **清理**：四个可组合选项——已停止的容器 / 悬空镜像 / 未使用的网络 / 未使用的卷，分别对应 Docker prune；执行前显示可清理数量，不可恢复。
- **设置**：顶栏齿轮打开，外观三选（跟随系统 / 浅色 / 深色）+ 自动更新三个开关（启动时检查 / 自动下载并安装 / 安装后自动重启，默认开启）。

操作反馈按归属分流：失败原因 / 复制确认 / 更新通知走右下角浮层；拉取进度留在拉取弹窗；清理逐项结果留在清理弹窗的结果视图；操作成功不提示。底栏只报稳定状态，不承载操作文本。

## 7. 命令行参数

| 参数 | 行为 |
| --- | --- |
| `--version` / `-V` | 打印版本后退出，不初始化 GUI、不连 Docker |
| `--help` | 打印帮助后退出 |
| `--status` | 打印 running / not running，退出码 0 / 1 |
| 其它参数 | 一律按正常启动 GUI 处理 |

三者都在拿单实例锁之前处理，已有实例运行时照常可用。

## 8. 自动更新与数据口径

启动后延迟检查 Releases，带节流（可在设置里关闭）；发现新版本时顶栏更新图标带徽标点。清单只广播版本号，资产地址由版本号派生，完整性只认 `checksums.txt`（SHA-256），签名校验或哈希冲突即拒绝安装。用户级安装静默自替换免授权；系统级 deb 安装由验签启动器挑选用户目录里更高且校验通过的版本。开发构建 / 非 Linux 只提示并打开下载页。

底栏「镜像大小」是全部镜像占用之和；「磁盘」是容器合计（镜像按 id 去重 + 可写层 + 挂载卷）。stats 连续 3 轮、磁盘连续 2 轮无样本时，顶栏亮过期小圆点而不是弹窗。
